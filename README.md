## The point of view

> Ex-operations guy who got tired of manual work. Now I build tools so nobody else has to suffer.

My path into software didn't start with side projects. It started with shipping commercial platforms for paying clients. After six-plus years running operations, HR, and procurement, I got tired of watching businesses drown in manual work, so I started building the tools to fix it.

My operational background runs through everything I build. I don't write code for the sake of it. I build systems non-technical owners can actually run themselves: their own data, their own pricing, their own content, without calling a developer every time something needs to change.

I use AI heavily as a development tool for architecture, debugging, and routine work. I don't treat it as a substitute for engineering judgment. I architect the systems, review every critical line, validate outcomes, and take full responsibility for the final product.
